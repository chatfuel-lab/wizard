# Support

## Something is broken

[Open an issue](../../issues/new/choose). Include the output of

```bash
npx @chatfuel/wizard doctor
```

and redact anything token-shaped first — a token that reaches a public issue is a token to
rotate.

## Something does not work and you are not sure it is broken

Ask in [Discussions](../../discussions) or in the Discord:
<https://discord.gg/TmrgcjVqFf>. "How do I…", "is this supposed to…" and "has anyone…"
all belong there, and an answer usually arrives faster than a triage does.

## You found a vulnerability

Do not open an issue. Use private vulnerability reporting — the Security tab, "Report a
vulnerability". [SECURITY.md](SECURITY.md) has the scope.

## You want a feature

[Open a feature request](../../issues/new/choose), or float it in Discussions first if it is
more of a shape than a request. Both are read.

## You want to change the code

[CONTRIBUTING.md](CONTRIBUTING.md) — the seven gates, one commit per pull request, and the rules
about what may reach a scaffolded project.

## What is not supported here

The Chatfuel product itself. This repository is the open-source wizard and the app it writes;
questions about the hosted dashboard, billing or the API's own behaviour belong to Chatfuel
support at <https://chatfuel.com>.
